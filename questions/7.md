* claude.ai answer: "Helgrind reports a data race on done, because the child writes it and the parent reads it with no locks held. The program happens to produce the right output, but it's relying on behavior the language doesn't guarantee, and it has no memory ordering between the child's work and the parent seeing done. The correct fix is a lock plus a condition variable (or an atomic variable)."
